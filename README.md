# Movie Theater Ticket Booking App

A simple and interactive movie ticket booking application built using **HTML**, **CSS**, and **AngularJS (1.8.2)**.

## 🚀 Features

- Select from a list of movies with images
- Choose available showtimes dynamically based on the selected movie
- Enter number of tickets (1–10)
- Automatic total price calculation based on movie-specific ticket prices
- Simple booking confirmation popup
- Responsive and visually appealing UI

## 📦 How to Use

1. Clone or download the repository.
2. Open `index.html` in any modern web browser (no server setup needed).
3. Use the interface to:
   - Select a movie
   - Choose a showtime
   - Input the number of tickets
   - Click **"Book Tickets"** to see confirmation

## 🎬 Movie Data (Sample)

- **KGF**: $10/ticket, Showtimes: `10:00 AM`, `1:00 PM`, `6:00 PM`
- **Kanthara**: $12/ticket, Showtimes: `11:00 AM`, `2:00 PM`, `7:00 PM`
- **Googly**: $8/ticket, Showtimes: `9:00 AM`, `12:00 PM`, `5:00 PM`
